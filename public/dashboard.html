Picking / Surtido de salida

Prepara productos para salida mediante escaneo, validación y surtido. No es una entrada de mercancía.

1. Código leído SKU o barras capturado
2. Producto validado Catálogo y existencia
3. Descuento de stock Salida automática
4. Trazabilidad Evento registrado

Escanea el código de barras desde handheld o lector físico. El sistema valida producto, descuenta stock y registra trazabilidad.
