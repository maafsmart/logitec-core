Picking / Surtido de salida

Prepara productos para salida mediante escaneo, validación y surtido. No es una entrada de mercancía.

1. Código leído SKU o barras capturado
2. Producto validado Catálogo y existencia
3. Descuento de stock Salida automática
4. Movimientos Evento registrado

El sistema descuenta solo la línea exacta de inventario (proyecto, ubicación y estatus). Si el SKU está en varias líneas, debes seleccionarlas: no se descuenta al azar. Primero puede escanearse el código; si hay ambigüedad, elige ubicación/estatus y vuelve a confirmar.

Órdenes de surtido / Requisiciones

Crea solicitudes para preparar productos de salida. Puede ser una orden simple o una orden por volumen.

La requisición no descuenta inventario. El stock se descuenta únicamente al surtir mediante Picking/Salida.

Cliente principal: AVIAT · No registra entrada de inventario

Entrada masiva aumenta existencias. Órdenes de surtido solicitan preparación de salida. Picking ejecuta el surtido y puede descontar. Salidas confirman el despacho.

Nueva orden de surtido

Agrega varias líneas con el mismo folio. Se creará una tarea de surtido por cada línea.
